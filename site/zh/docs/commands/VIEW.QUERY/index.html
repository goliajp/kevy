VIEW.QUERY

按视图的既定顺序翻页取出成员，可通过 VIA 模板顺带把字段取回来。

VIEW.QUERY name [LIMIT n] [CURSOR c] [FIELDS field ...]
分组
视图
起始版本
3.0.0
参数个数
至少 2 个
标志
readonly extension

复杂度

virtual：O(log N_order + candidates * leaves) —— 它顺着 ORDER 索引流式扫描，对每个候选逐个探测是否属于该视图，取够 limit 就停，因此从不物化整个成员集合。materialized：O(log M + limit)。加上 FIELDS 与 VIA 会多出第二次扇出，用来把原行取回来。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

kevy 独有

kevy 独有：Redis 没有对应物。刻意不做的部分：没有 join，视图层没有谓词，视图自身不做投影，没有 HAVING，也没有聚合。
