ZSCAN

遍历 zset 的成员与分值（单批次游标）。

ZSCAN key cursor [MATCH pattern] [COUNT count]
分组
有序集合
起始版本
1.0.0
参数个数
至少 3 个
标志
readonly

复杂度

O(N) —— 整个 zset 会被完整物化。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

有差异

有差异：它不是游标迭代器 —— 每次调用都把整个 zset 返回，游标恒为 0，COUNT 解析过后直接忽略。
