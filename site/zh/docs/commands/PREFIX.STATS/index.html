PREFIX.STATS

报告某个 key 前缀的 key 数量与字节数统计。

PREFIX.STATS prefix
分组
迁移
起始版本
3.0.0
参数个数
恰好 2 个
标志
readonly extension

复杂度

O(该 shard 上的 key 数) —— 每个 shard 都要把键空间完整走一遍；前缀这个维度无法预先算好。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

kevy 独有

kevy 独有：最接近的是 INFO keyspace 里的 db0:keys=N,expires=M —— 同样是那两个计数，但它是整库口径、靠一个计数器 O(1) 拿到的，我们这条是按前缀的，因此代价是 O(键空间)。
