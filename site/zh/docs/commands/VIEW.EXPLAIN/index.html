VIEW.EXPLAIN

展开视图的组合树，并给出每个叶子的基数。

VIEW.EXPLAIN name
分组
视图
起始版本
3.0.0
参数个数
恰好 2 个
标志
readonly extension

复杂度

O(各叶子的 (log N + matched) 之和) —— 每个叶子的基数都是真数出来的，所以在一个宽泛的叶子上跑 EXPLAIN，代价与真去数它一样。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

kevy 独有

kevy 独有：最接近的是 FT.EXPLAIN，但它返回的是查询树，而不是每个叶子的基数。
