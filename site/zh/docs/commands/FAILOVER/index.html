FAILOVER

有计划的零丢失切换：停写、等目标副本追平、把它提升为主、然后本机改为跟随它。

FAILOVER host port [TIMEOUT ms] | ABORT
分组
复制
起始版本
3.0.0
参数个数
至少 3 个
标志
write admin

复杂度

命令本身 O(1) —— 切换在后台进行，不断轮询目标直到它追平为止。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

有差异

有差异：Redis 的语法是 FAILOVER [TO host port [FORCE]] [ABORT] [TIMEOUT ms]，目标可选；kevy 的是 FAILOVER host port [TIMEOUT ms] | ABORT —— 目标是必填的位置参数，而且这里给的 port 是目标的客户端端口。
