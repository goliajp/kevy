SLOWLOG

查看或重置慢命令日志。

SLOWLOG GET [count] | LEN | RESET | HELP
分组
服务器
起始版本
1.0.0
参数个数
至少 2 个
标志
readonly admin

复杂度

GET：O(S) 扇出，外加 O(L log L) 的归并。LEN：O(S)。RESET：O(S)。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

有差异

有差异：日志是按 shard 各存一份的，GET 按时间戳跨 shard 归并，因此 id 不是全局单调的；每条记录的 client-addr 与 client-name 都是空字符串。
