HELLO

握手：返回服务器信息，并切换 RESP 协议版本（2 或 3）。

HELLO [protover]
分组
连接
起始版本
1.0.0
参数个数
至少 1 个
标志
readonly

复杂度

O(1)。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

有差异

有差异：只有 HELLO [2|3] 真正生效 —— 后面的 AUTH 与 SETNAME 尾巴会被解析掉然后丢弃，因为 kevy 没有 AUTH，而且这种写法也不会设置连接名。
