PUBLISH

向频道投递一条消息；返回接收者数量。

PUBLISH channel message
分组
发布订阅
起始版本
1.0.0
参数个数
恰好 3 个
标志
readonly pubsub

复杂度

频道查找 O(1)，外加 O(P) —— 即便一个都匹配不上，也要把已注册的模式线性走一遍，逐个做 glob 匹配。投递只扇出到有订阅者的那些 shard。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。
