DEBUG

调试子命令；SLEEP 会阻塞一个 shard，其余子命令一律容忍并返回 OK。

DEBUG SLEEP seconds | subcommand [args ...]
分组
服务器
起始版本
1.0.0
参数个数
至少 2 个
标志
readonly admin

复杂度

SLEEP：把应答的那个 shard 的 reactor 线程停住指定时长（其余 shard 照常服务）。其它子命令：O(1)。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

有差异

有差异：只有 SLEEP 真正有效果，而且它阻塞的是一个 shard，不是整个服务器；其余子命令一律接受并返回 OK，但什么都不做。
