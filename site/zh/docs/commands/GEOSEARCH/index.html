GEOSEARCH

从某个成员或某个坐标出发，按半径或矩形范围搜索成员。

GEOSEARCH key FROMMEMBER member|FROMLONLAT longitude latitude BYRADIUS radius m|km|mi|ft|BYBOX width height m|km|mi|ft [ASC|DESC] [COUNT count [ANY]] [WITHCOORD] [WITHDIST] [WITHHASH]
分组
地理空间
起始版本
1.0.0
参数个数
至少 4 个
标志
readonly

复杂度

O(log N + C) —— 最多九个相邻区块，每个都是分值树上 seek 出来的一段切片；C 为命中 geohash 区块内的成员数（分块现在连迭代一起省，不只是距离计算）。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

有差异

有差异：只读形式下 STOREDIST 会被接受并忽略；COUNT 0 是错误。
