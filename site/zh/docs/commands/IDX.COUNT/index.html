IDX.COUNT

统计匹配区间谓词或等值谓词的索引条目数。

IDX.COUNT name RANGE min max | EQ value
分组
索引
起始版本
3.0.0
参数个数
至少 4 个
标志
readonly extension

复杂度

每个 shard 上 O(log N + matched) —— 它不是 O(1) 的计数器，也不是 B-tree 的 rank 查询，而是把命中的那段区间数了一遍。

复杂度与兼容性是从 kevy 的实现里读出来的、不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误、但不是。

与 Redis 的兼容性

kevy 独有

kevy 独有：最接近的是 FT.SEARCH 配 LIMIT 0 0。
