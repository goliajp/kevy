命令 / 迁移 / PREFIX.DIGEST

PREFIX.DIGEST

对某个前缀下的行做一个与顺序无关的校验和，用于迁移核对。

PREFIX.DIGEST prefix
分组
迁移
起始版本
3.0.0
参数个数
恰好 2 个
标志
readonly extension

复杂度

每个 shard 上遍历 O(该 shard 上的 key 数)，再加上 O(各行大小之和) 做摘要。逐行的摘要之间做 XOR，因此结果与顺序无关，shard 数改变后依然可比。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

kevy 独有

kevy 独有：最接近的是 DEBUG DIGEST —— 性质相仿（Redis 也是把逐 key 的摘要 XOR 起来），但 Redis 的是整库口径且藏在 DEBUG 后面，我们这条是按前缀的（迁移真正关心的单位），而且是一条受支持的正式命令。
