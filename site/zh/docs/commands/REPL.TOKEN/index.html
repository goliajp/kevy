REPL.TOKEN

kevy 扩展：签发一个 read-your-writes 令牌 —— 每个 shard 一对 [generation, offset](主库报告自己 feed 的尾部，副本报告自己已应用到的位置)。

REPL.TOKEN
分组
复制
起始版本
3.0.0
参数个数
恰好 1 个
标志
readonly extension

复杂度

O(S) —— 每个 shard 一对 (generation, offset)。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

kevy 独有

kevy 独有：read-your-writes 令牌。Redis 里最接近的概念是 master_repl_offset，但它不是可续读的按 shard 游标。
