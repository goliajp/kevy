CLIENT

连接的查看与控制子命令。

CLIENT ID | GETNAME | SETNAME name | LIST | KILL filter | INFO | NO-EVICT ON|OFF
分组
服务器
起始版本
1.0.0
参数个数
至少 2 个
标志
readonly admin

复杂度

ID / GETNAME / SETNAME / INFO：O(1)。LIST：O(S) 扇出，外加 O(C) 行。KILL：O(S) 扇出，外加 O(C) 扫描。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

有差异

有差异：只有 ID / GETNAME / SETNAME / INFO、裸形式的 LIST、按 ID 或 ADDR 的 KILL 以及 NO-EVICT；CLIENT LIST 带过滤器属于语法错误，其余子命令（PAUSE、REPLY、TRACKING、UNBLOCK、NO-TOUCH）一律按未知命令处理。
