DEL

删除一个或多个 key。

DEL key [key ...]
分组
通用键操作
起始版本
1.0.0
参数个数
至少 2 个
标志
write

复杂度

O(N) 个 key；某个 key 若存的是含 M 个元素的容器，还要为它多付 O(M) —— 析构时要走一遍容器。

复杂度与兼容性是从 kevy 的实现里读出来的，不是抄 Redis 的文档。有几条确实不一样 —— 它们看起来像笔误，但不是。

与 Redis 的兼容性

有差异

有差异：多 key 形式按 shard 拆开执行再把结果相加，中间没有屏障，所以跨 shard 不是原子的；单 key 形式则是原子的。
