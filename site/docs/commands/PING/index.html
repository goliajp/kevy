PING

Ping the server; returns PONG or echoes the optional message.

PING [message]
Group
Connection
Since
1.0.0
Arity
at least 1
Flags
readonly

Complexity

O(1)

Complexity and compatibility are read out of kevy's implementation, not copied from Redis's reference. Several genuinely differ.

Redis compatibility

Differs

kevy has no RESP2 subscriber mode, so PING while subscribed does not switch to the array form and non-pubsub commands stay legal on a subscribed connection
