RPOP

Pop one or more elements from the tail of a list.

RPOP key [count]
Group
List
Since
1.0.0
Arity
at least 2
Flags
write

Complexity

O(C) elements popped

Complexity and compatibility are read out of kevy's implementation, not copied from Redis's reference. Several genuinely differ.

Redis compatibility

Differs

RPOP key 0 on an existing key replies a nil array where Redis replies an empty array
