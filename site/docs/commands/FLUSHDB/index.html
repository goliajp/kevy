FLUSHDB

Delete every key of the current database (kevy is single-DB: same as FLUSHALL).

FLUSHDB
Group
Server
Since
1.0.0
Arity
at least 1
Flags
write

Complexity

O(N + S) — identical to FLUSHALL

Complexity and compatibility are read out of kevy's implementation, not copied from Redis's reference. Several genuinely differ.

Redis compatibility

Differs

kevy is single-DB, so FLUSHDB is an alias of FLUSHALL; ASYNC / SYNC are ignored
