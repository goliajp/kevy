Commands / String / MGET

MGET

Return the values of multiple keys (cross-shard gather).

MGET key [key ...]
Group
String
Since
1.0.0
Arity
at least 2
Flags
readonly

Complexity

O(N) keys, one O(1) probe each on the owning shard

Complexity and compatibility are read out of kevy's implementation, not copied from Redis's reference. Several genuinely differ.

Redis compatibility

Differs

keys are grouped by shard and each shard is probed independently, so the reply is not a point-in-time snapshot across shards
