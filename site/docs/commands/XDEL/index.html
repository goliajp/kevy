Commands / Stream / XDEL

XDEL

Delete entries from a stream by ID.

XDEL key id [id ...]
Group
Stream
Since
1.0.0
Arity
at least 3
Flags
write

Complexity

O(D log N + N*F) for D ids — NOT O(1): the trailing weight recompute is linear in the whole stream

Complexity and compatibility are read out of kevy's implementation, not copied from Redis's reference. Several genuinely differ.

Redis compatibility

Compatible

Behaves as Redis does.
