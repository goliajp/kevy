INCRBYFLOAT

Increment the float value of a key by the given amount.

INCRBYFLOAT key increment
Group
String
Since
1.0.0
Arity
exactly 3
Flags
write

Complexity

O(1)

Complexity and compatibility are read out of kevy's implementation, not copied from Redis's reference. Several genuinely differ.

Redis compatibility

Differs

arithmetic is f64 and the reply uses Rust's shortest-round-trip float printer, not a long double accumulator, so trailing digits can diverge from Redis
