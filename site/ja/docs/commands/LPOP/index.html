コマンド / リスト / LPOP

LPOP

リストの先頭から要素を一つ以上 pop する。

LPOP key [count]
グループ
リスト
追加バージョン
1.0.0
引数の数
2 個以上
フラグ
write

計算量

O(C) —— pop した要素数 C。

計算量と互換性は kevy の実装から読み取ったものであり、Redis のドキュメントを写したものではない。実際に異なるものがいくつかある。

Redis との互換性

差異あり

差異あり。既存のキーに対する LPOP key 0 は、Redis が空の配列を返すのに対し nil 配列を返す。
