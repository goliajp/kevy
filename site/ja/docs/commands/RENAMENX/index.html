RENAMENX

変更先が存在しない場合に限りキーの名前を変更する(書き込みは runtime の Op 層でルーティングされる)。

RENAMENX key newkey
グループ
汎用キー操作
追加バージョン
1.0.0
引数の数
ちょうど 3 個
フラグ
write

計算量

文字列値なら O(1)。要素数 M のコレクションなら O(M)。

計算量と互換性は kevy の実装から読み取ったものであり、Redis のドキュメントを写したものではない。実際に異なるものがいくつかある。

Redis との互換性

差異あり

差異あり。shard をまたぐ RENAMENX は Take、Put、拒否時の復元という非アトミックな手順を踏むため、元のキーがキースペースから消えている窓が生じる。
