SINTERSTORE

指定したセットの積集合を destination に格納する。

SINTERSTORE destination key [key ...]
グループ
集合
追加バージョン
1.0.0
引数の数
3 個以上
フラグ
write

計算量

O(元セットの濃度の総和) に加え O(結果の要素数)。小さいセットから先に処理しない点は SINTER と同じ。

計算量と互換性は kevy の実装から読み取ったものであり、Redis のドキュメントを写したものではない。実際に異なるものがいくつかある。
