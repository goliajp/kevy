XPENDING

コンシューマーグループの pending エントリを、サマリ形式または拡張形式で参照する。

XPENDING key group [[IDLE min-idle-time] start end count [consumer]]
グループ
ストリーム
追加バージョン
1.0.0
引数の数
3 個以上
フラグ
readonly

計算量

サマリ形式は O(P*C) —— コンシューマーごとの集計は PEL の各行に対する線形探索になる。拡張形式は O(log P + K)。

計算量と互換性は kevy の実装から読み取ったものであり、Redis のドキュメントを写したものではない。実際に異なるものがいくつかある。
