GEOSEARCHSTORE

source に対して GEOSEARCH を実行し、その結果を destination に書き出す。

GEOSEARCHSTORE destination source FROMMEMBER member|FROMLONLAT longitude latitude BYRADIUS radius m|km|mi|ft|BYBOX width height m|km|mi|ft [ASC|DESC] [COUNT count [ANY]] [STOREDIST]
グループ
地理空間
追加バージョン
1.0.0
引数の数
5 個以上
フラグ
write

計算量

検索に O(log N + C)、書き込み先を自身の shard 上で書き直すのに O(D + K log K)。

計算量と互換性は kevy の実装から読み取ったものであり、Redis のドキュメントを写したものではない。実際に異なるものがいくつかある。

Redis との互換性

差異あり

差異あり。STOREDIST はクエリが指定した単位で距離を格納する(Redis も同じ)。書き込み先は自身の shard 上で更新されるため、source と destination は別のコアに載り得るし、書き込みは読み取りと原子的にならない。
