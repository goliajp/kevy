FLUSHALL

全 shard の全 key を削除する。

FLUSHALL
グループ
サーバー
追加バージョン
1.0.0
引数の数
1 個以上
フラグ
write

計算量

fan-out は O(S)。shard ごとに O(N/S) のクリアに加えて、WATCH の無効化と feed generation の更新を行う。

計算量と互換性は kevy の実装から読み取ったものであり、Redis のドキュメントを写したものではない。実際に異なるものがいくつかある。

Redis との互換性

差異あり

差異あり。ASYNC / SYNC は受理した上で無視する(flush は shard 単位で常に同期実行)。CDC の feed generation を進めるため、稼働中の FEED カーソルは resync エラーを受け取る。
