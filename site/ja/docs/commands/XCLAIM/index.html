XCLAIM

指定した id の idle な pending エントリを、コンシューマーへ claim する。

XCLAIM key group consumer min-idle-time id [id ...] [IDLE ms] [TIME unix-time-milliseconds] [RETRYCOUNT count] [FORCE] [JUSTID]
グループ
ストリーム
追加バージョン
1.0.0
引数の数
6 個以上
フラグ
write

計算量

O(A * (log P + log N))。

計算量と互換性は kevy の実装から読み取ったものであり、Redis のドキュメントを写したものではない。実際に異なるものがいくつかある。

Redis との互換性

差異あり

差異あり。IDLE / TIME / RETRYCOUNT / FORCE / JUSTID は解析するが、LASTID は解析しない。key または group が存在しない場合は NOGROUP ではなく「no such key」を返す。
