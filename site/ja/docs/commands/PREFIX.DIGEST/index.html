PREFIX.DIGEST

prefix 配下の行に対する順序非依存のチェックサム。移行時の検証に使う。

PREFIX.DIGEST prefix
グループ
マイグレーション
追加バージョン
3.0.0
引数の数
ちょうど 2 個
フラグ
readonly extension

計算量

全 shard で、走査に O(keys on the shard)、ダイジェスト計算に O(sum of row sizes)。行ごとのダイジェストを XOR で畳み込むため、結果は順序に依存せず、shard 数が変わっても安全に比較できる。

計算量と互換性は kevy の実装から読み取ったものであり、Redis のドキュメントを写したものではない。実際に異なるものがいくつかある。

Redis との互換性

kevy 固有

kevy 固有。最も近いのは DEBUG DIGEST —— 種類としては同等であり(Redis も key ごとのダイジェストを XOR する)、違いは対象と位置づけにある。Redis のものは DB 全体を対象とし DEBUG の裏に置かれているが、kevy のものは prefix 単位(移行が実際に気にする単位)であり、正式にサポートされた verb である。
