コマンド / マイグレーション / PREFIX.STATS

PREFIX.STATS

key の prefix に対する key 数とバイト数の統計を返す。

PREFIX.STATS prefix
グループ
マイグレーション
追加バージョン
3.0.0
引数の数
ちょうど 2 個
フラグ
readonly extension

計算量

全 shard で keyspace を全走査するため、shard あたり O(keys on the shard)。prefix ごとの集計は事前計算できない。

計算量と互換性は kevy の実装から読み取ったものであり、Redis のドキュメントを写したものではない。実際に異なるものがいくつかある。

Redis との互換性

kevy 固有

kevy 固有。最も近いのは INFO keyspace の db0:keys=N,expires=M —— カウンタが 2 つという点は同じだが、あちらは DB 全体をカウンタから O(1) で返すのに対し、kevy のものは prefix 単位であり、したがって keyspace のサイズに比例する。
