What this actually is

        
The engine, not a wrapper

        

          The @goliajp/kevy package:
          a 416 KB wasm32-unknown-unknown module behind a hand-written
          ES-module loader. Zero dependencies, and no binding generator — the C ABI
          is written by hand, so there is no wasm-bindgen glue between you and it.
        

        

          Every operation executes in wasm linear memory. Storage is where the log lands,
          not where the lookups happen.
        

      

      

        
Measured, including the loss

        
Where it wins, and where it does not

        

          Against IndexedDB it is 77–189× faster. Against localStorage it
          wins writes 4.9× — and loses small reads, because a native synchronous
          hash lookup crosses no boundary and a wasm call does.
