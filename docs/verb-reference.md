# Verb reference

Every wire-reachable verb, from the server's own metadata table
(`COMMAND DOCS` answers from the same rows). GENERATED by
`cargo run -p kevy --bin gen_docs .` — do not edit by hand.

187 verbs. Flags: `write`/`readonly` (side-effect class),
`admin`, `blocking`, `pubsub`, `transaction`, `extension`
(kevy-specific surface; argument 1 is a catalog name, not a key).

## connection

| Verb | Arity | Flags | Summary |
|---|---|---|---|
| `ECHO message` | 2 | readonly | Return the given message. |
| `HELLO [protover]` | -1 | readonly | Handshake: report server info and switch RESP protocol version (2 or 3). |
| `PING [message]` | -1 | readonly | Ping the server; returns PONG or echoes the optional message. |
| `QUIT` | 1 | readonly | Close the connection after replying OK. |
| `SELECT index` | 2 | readonly | Select the logical database; kevy is single-DB and only accepts index 0. |
