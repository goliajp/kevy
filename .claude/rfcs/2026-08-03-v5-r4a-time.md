# R4a-time:日期算术 —— R4a 清单最后一个"引擎缺"红项

> 实证形状(R4A-SQL-SHAPE-INVENTORY):S1' `snoozed_until > NOW()`;
> S4 corpus 8 条日期探针(now_and_date_arith/interval/date_functions…);
> 判定"引擎缺(epoch i64 range 覆盖 BETWEEN;日历算术 app 侧)",
> 分量中-高(兼容面大头之一)。closed 后 R4a 无引擎缺红项。

## 〇、上位拍板

1. **列模型不变**:时间列 = 声明 i64(epoch 秒;units belong to the
   caller,WINDOW 同款哲学)。引擎补的是"查询侧把人话变成 i64"的算术,
   不是新类型。
2. **石头 + 薄接线**:日历算术是纯函数(civil-from-days 整数公式,闰年
   /月长/月末 clamp 全代数)→ 新石头 crate `kevy-time`(零依赖,`now`
   永远作参数传入 —— 石头不碰时钟);接线 = 查询 bound 预处理(`@`
   前缀表达式 → i64 十进制字面量),现有 coerce/range/claused/WHERE
   下游**零改动**。
3. **UTC only**;时区换算 app 侧(timestamptz 兼容具名拒绝,记档)。
   date_trunc 分桶(报表 GROUP BY day)= v-next 发散区,不在本程。

## 一、kevy-time(石头)

- `civil_from_epoch(secs) -> (y, m, d, h, min, s)` / `epoch_from_civil`
  (Hinnant civil 算法,纯整数;proleptic Gregorian,负 epoch 正确)。
- `add_months(secs, n)`:日历月加减,月末 clamp(1-31 → 2-28/29)。
- `eval(expr, now) -> Option<i64>`:查询表达式求值 ——
  - `@now`;
  - `@now±<n><unit>`,unit ∈ s|m|h|d|w(纯秒算术)|mo|y(走
    add_months);
  - `@YYYY-MM-DD` = 当日 00:00:00;`@YYYY-MM-DDThh:mm:ss`。
  - 畸形 → None(上层具名拒绝,不猜)。
- 单测:civil 往返 property(±50 万天扫)、闰年/世纪规则、月末 clamp
  表、eval 全形状 + 拒绝面。

## 二、接线(两面同构)

- **server**:`args_scalar` 的 bound 进 coerce 前过
  `kevy_time::eval`(bytes 以 `@` 起时);`now` 每查询取一次
  (同查询内 `@now` 一致)。覆盖 RANGE/EQ 两端、WHERE 的 EQ/RANGE
  分量、FILTER 的 RANGE/EQ 值 —— 即"凡 bound 皆可 `@`"。
  解析失败 → BADARGS 具名(现有姿势)。
- **embedded**:dispatch_argv(RESP 面)同一预处理;Rust API 面不加
  糖 —— 调用方有真语言,直接 re-export `kevy_time` 供其算 i64。
- `@` 冲突面:bound 字面量今天不可能以 `@` 起(i64/f64 十进制,str
  列的 EQ 值理论可含 `@` —— 预处理**只对声明 i64 的列/字段**生效,
  str 列原样直传,无歧义)。

## 三、gate

1. kevy-time property/表测全绿(石头标准)。
2. e2e:`@` bound 与手算 i64 bound 逐字节同答(RANGE/WHERE/FILTER
   各形);畸形表达式具名拒;str 列带 `@` 值原样命中。
3. 无 `@` 查询 byte-identical(纯前缀分支)。
4. 清单回写:日期算术行 引擎缺 → 已有(@-bound);R4a 无引擎缺红项。

## 四、发散区

1. date_trunc 分桶进 AGG(GROUP BY day/week/month)—— 报表形状,
   等 R4b/实证再定。
2. 时区表(TZif 解析,纯 Rust)—— timestamptz 兼容真需求出现时。
3. `@now` 的多 shard 一致性:origin 求值一次随 argv 下发(现设计天然
   如此 —— 预处理在 origin 的 args 层,shard 看到的已是 i64)。
