## 一、做了 + 已验证

### P6 — availgate failover wedge(关键路径,不绿不发)

**根因**:generation fence 有一个 fresh-cursor 例外。呈报
`gen 0 / offset 0` 的 cursor 被当作"空 replica",采纳 feed 的
generation 并从 offset 0 流帧——这只在「feed 的 offset 空间覆盖了
store 的整个生命」时成立。促升 bump **换掉整个 source**(缓冲帧全弃、
`next_offset` 归 0)却保留 store;采纳后的 cursor 落在
`sent == next == 0`,被读成"恰好追平",于是永不 ship,而 1Hz 心跳照发
—— `master_link_status:up`、`io 0s`、键空间静默分叉。促升窗口(写闸随
epoch 立即开,各 shard 要等自己的 tick 才 fence)内被接受的写入会被
bump 销毁,那正是 availgate 等 60 秒的 `postfail`。带数据的**非干净
重启**同样把 offset 归零,所以这个洞不止 failover。

**修**:gen 不匹配一律 ship snapshot,无例外。无 claim 的 cursor 不等
于空 replica(runner 的 cursor 存在线程里,每次 respawn 都归零,所以
一个带着整套旧数据的 replica 在 wire 上与空节点无法区分);帧流只能
新增和覆盖,永远删不掉 replica 有而 primary 没有的键——只有快照能
替换键空间。这也正是 Redis 的 full-resync 模型。

**验证**(全部实跑):
- 新 e2e `promoted_node_ships_its_keyspace_to_a_fresh_cursor` 红→绿;
  修前两种红脸都复现过(十次心跳无快照 = availgate 的停滞;只收到
  bump 后一帧而 50 个旧键永不到达 = 更危险的静默分叉)。
- `cargo test -p kevy --test replication` 26/26;kevy-cluster-rw、
  kevy-rt / kevy-replicate / kevy-persist 套件全绿。
- **盒上 availgate 争用循环 20/20 绿**(32 contenders / 16 核)。
- 盒上 repligate PASS、crashgate PASS。
- 分支 CI 全绿;develop CI 的 contract gates(含 availgate)PASS。

**方法论收获**:争用循环**不是**配方——修前的探针版跑了 28 轮争用没
复现,因为窗口只有约一个 tick 宽。真正破案的是确定性 in-process 复现。
另外,pump 里那两个**唯一没有日志**的臂,正是 bug 所在的两个臂。

### RC 之后新增的一项(属主需知道 tag 会包含它)

**epoll/kqueue 的 tick 每 100ms 同步排空 AOF writer lane** —— 起因是
tick 把"没变过的 appendfsync"当成待应用的策略切换,而切换协议按设计
要先排空 offload driver(poll 反应堆上是忙等)。修 = 只有策略**真的
变了**才算待切换。

- **不是 5.0 的回归**:writer lane 与切换排空纪律都是 5.1 新增的,所以
  5.0 既没有 lane 也没有排空它的 tick。修的是 S3 的收益能到账多少。
- **实测**(盒上,同构建):epoll firehose 最坏反应堆停顿 790ms →
  34-42ms、最坏客户端往返 862ms → 14-16ms、p99.9 123ms → 10ms、
  超 100ms 的迭代 97-106 次 → **0 次**;**tailgate 在 poll 反应堆上
  转绿**(此前四个数里红三个)。crashgate PASS(它管 `always` 语义,
  正是这条改动经过的路径)。分支 CI 全绿。
- 定位方式全程是测量:`reactor_ticks_total` 把最高水位 gauge 变成可读的
  一对(节拍其实健康,38/40Hz,证伪了我先前"约 2Hz"的读法)→
  `KEVY_DEBUG_SLOW_ITER_MS` 把停顿钉在 tick 相且 events=0 →
  拆 tick 体钉到 `apply_live_runtime_config` 一个调用(891ms 里占 884ms)。
- finding=`bench/FINDING-2026-08-12-epoll-tick-drained-the-lane.md`。
