运行

从 6.4 升级到 7.0

协议侧无需改动，但要检查 maxmemory，并先升级主节点再升级副本；按 API Guidelines 整理过的 Rust API、移到 --kevy 后面的 kevy-cli 工具、变了的回复、退回 6.4 之前要做什么、修掉了哪些丢数据的缺陷。

从 6.3 升级到 6.4

代码无需改动；五处原本答错的结果现在对了，从两极附近的 GEOSEARCH 到一个 regexp 交替。

从 6.2 升级到 6.3

HRANDFIELD、能在线上设的 keyspace 事件开关、四处 RESP3 形状，以及一条修正过的 GEOPOS 回复。

从 6.2.0 升级到 6.2.1

服务器什么都没变；两个客户端 crate 终于以引擎的版本号到达 crates.io。

从 5.1 升级到 5.2

停 5.1、在同一目录起 5.2 —— Lua 方言与上游对齐。

从 5.0 升级到 5.1

停 5.0、同目录启 5.1——修掉一个读取隐患，去掉两处停顿。

从 4.x 升级到 5.0

停 4.1.1、同目录启 5.0——以及哪些行为变了。
